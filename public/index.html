Features

Built for real protection

VMdex runs your scripts inside a custom virtual machine with server-side runtime delivery and randomized instruction sets.

Custom VM

Scripts execute in a randomized virtual machine. Opcode mappings change every build.

Server-side runtime

The VM runtime is fetched at execution time, not embedded — no static bytecode to dump.

Fast output

Obfuscation finishes in seconds. Output size is padded to 200 KB minimum for consistency.

Loadstring mode

Generate a one-liner that fetches your script from our servers. Update it anytime without redistributing.

Luau native

Full Luau syntax support — types, generics, continue, string interpolation.

Anti-tamper

String encryption, opaque predicates, and integrity checks that fail loud.
